# نشر CifliX على Render من الهاتف

1. ارفع **محتويات هذا المجلد** إلى جذر مستودع GitHub (لا ترفع ملف ZIP وحده).
2. في Render اختر New > Blueprint ثم اربط المستودع الذي يحتوي render.yaml.
3. وافق على إنشاء Web Service بخطة Free.
4. انتظر نجاح النشر، ثم افتح رابط onrender.com الذي يظهر في لوحة Render.
5. اختبر /api/health ثم الصفحة الرئيسية.

الواجهة والخادم في خدمة واحدة؛ لذلك تستخدم الواجهة /api من نفس النطاق ولا تحتاج عنوان localhost أو إعداد CORS منفصل.

ملاحظات: خدمة Render المجانية تدخل السكون بعد 15 دقيقة من عدم وجود طلبات، وقد يستغرق أول طلب بعدها قرابة دقيقة لإعادة التشغيل. التخزين المحلي مؤقت. استخدم فقط المحتوى وروابط البث التي تملك تصريحاً بنشرها للجمهور، ولا تتجاوز DRM أو ضوابط الوصول.
